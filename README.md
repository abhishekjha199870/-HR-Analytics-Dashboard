# HR-Analytics-Dashboard

A Power BI and SQL dashboard built to monitor workforce metrics, employee performance, turnover, attrition, and HR performance indicators.

## Overview
This dashboard tracks:
- employee headcount
- attrition rate
- turnover and retention trends
- active employees
- average age
- average monthly income
- department and role analysis

## Business Objective
To track and display key HR metrics like employee headcount, turnover rate, attrition rate, active employee, avg age, avg monthly payment across gender, department, job role and age.

## KPI Highlights
- Total Employee
- Total Attrition
- Attrition Rate
- Active Employee
- Average of Age
- Average of Monthly Income

## Tools Used
- Power BI
- SQL
- DAX
- Power Query

## Key Features
- Employee headcount analysis
- Attrition monitoring
- Department and role analysis
- Age group insights
- Monthly income tracking
- Workforce planning support

## Business Insights

-Attrition analysis helps identify retention risks
-Department and role metrics improve workforce planning
-Age and monthly income data support hiring and compensation decisions
-Employee tracking helps monitor team stability
